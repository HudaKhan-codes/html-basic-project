# Student Registration Form 📚

A simple and beginner-friendly **Student Registration Form** website built using pure **HTML5**. This project was created as a foundational practice exercise to learn HTML tables, forms, and input elements.

---

## 🚀 Features

* **Class Schedule Table:** Displays available subjects, covered grades, and class timings in a structured tabular format.
* **Student Details Input:** Text fields to collect the student's name and email address.
* **Grade Selection:** Radio buttons allowing users to choose their respective grade level (Grade 5 to Grade 10).
* **Subject Preferences:** Checkboxes to select desired subjects (Web Development, Computer Science, English).
* **Gender Selection:** Radio options for gender specification.
* **Inquiry Section:** A text area for students or parents to ask questions or leave feedback.
* **Submission:** A functional submit button.

---

## 🛠️ Technologies Used

* **HTML5** (Semantic tags, tables, and form elements)
